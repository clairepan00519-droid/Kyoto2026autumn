# 狐光漫遊・挪威 20 天慢旅網站

在峽灣慢行，等一場北方的光。主角是北極狐「呆維」。

由「雪羽慢旅（北海道版 hk26）」移植而來，功能沿用：家人同步、離線 PWA、開場動畫、每日交通、住宿卡、收藏與預約、出發前待辦、每日回顧、MaMa 筆記、角落小驚喜、備份與快照。內容換成挪威 20 天行程，風格換成靛藍夜色＋暖杏橘＋極光青綠。

## nw2（改成淺色、北海道式緊湊排版、可選字體）

1. 整站改成淺色：淺紫灰底，點綴用木屋色票（暖杏橘、銅橘、藍紫）與極光色票（極光綠、天藍、透明紫、霧粉）。
2. 版型回到北海道版：標題在上、夜景插畫做成圓角卡片；每天的標頭是白色卡片，當天呆維插畫縮成提示條左邊的小圖，出門、交通、車程估算收在同一行；備註、雨天備案、可選極光改成精簡的小條。
3. 字體可以選：⚙️ →「字體」有 7 組，只改這支手機的顯示。全家預設是「標題仙人掌明體、內文芫荽」。

## nw1（第一版）

1. **行程**：2027/9/24–10/13 共 20 天（占位日期，全部未訂票）。每天有標題、副標、呆維插畫、出門時間、交通方式、純駕車估算（註明「估算，不含停留／天候延誤」）、執行備註、雨天／天候備案、可選極光（標「可選・不保證看到」）。
2. **出發日可以改**：「環線」頁最上方改出發日，每天日期與住宿日期一起平移；以 Europe/Oslo 的日曆日計算，不做 UTC 換算。D1、D20 標示台灣時間。
3. **D12 擇一**：A Ramberg＋Flakstad／B Å＋Sørvågen，切換後標題、景點、交通一起換，不會合併在同一天。
4. **整天調換**（編輯模式，每天標頭的「⇄ 和另一天調換」）：同一段住宿裡的兩個觀光日直接換；跨住宿區或碰到交通日，會先跳出提醒，請自己檢查住宿、租車、航班與船票。調換過的日子會標示，環線頁可以「全部還原」。
5. **住宿**：依 8 段連住分組（共 17 晚，D1、D19 在機上）。同一段只有一張住宿卡，連住的每天都顯示同一間。可填名稱、地址、Airbnb 連結、入住／退房時間，以及廚房、停車、暖氣、洗衣機（待確認／有／無）。
6. **交通、船旅與票券**：華航往返、AMS–BGO、BGO–SVJ、三段租車、沿岸郵輪、TOS–AMS，初始全部「待確認」。可填航班號／船名、確認編號、時間、網址、費用、備註，上傳截圖。
7. **天氣**：Open-Meteo 的 MET Norway 模式（`metno_seamless`），抓不到時退回一般預報；每個地點有 yr.no 10 天預報連結。顯示的是「現在」的天氣，不是旅行當天的預報。日出日落用天文公式依挪威當地時間估算。降雪、強風與結冰提醒沿用北海道版的降雪模組。
8. **沒有假資料**：票價、班次、營業時間、極光機率都不填；即時交通只放官方連結（Statens vegvesen、Avinor、Hurtigruten、Havila、yr.no、Visit Tromsø、Visit Norway）。
9. **呆維**：44 張插畫轉成 WebP（約 5.4 MB）。每日插畫、7 個導覽圖示、6 個互動姿勢、8 種心情（每日回顧可多選）、開場動畫、角落小知識（每則附官方來源）。
10. **拿掉的北海道功能**：「給司機看」日文卡（挪威不需要）。吃·挪威／逛·挪威沒有預設店家，需要時在編輯模式新增。

## 版面與字體（nw2–nw6）

1. **淺色主題**：底色淺灰紫，主色取自小木屋配色（杏橘、銅橘、靛藍）與極光配色（藍、青綠、淡紫）。
2. **版面**：首頁是滿版插畫標頭（NORWAY · 2027、手寫標題、左下角日期），下面依序是「出發前準備」卡、行程／天氣／交通／路線／吃逛分頁、日期列、每日大圖與路線，底部是線條圖示導覽列。
3. **字體**：標題用「辰宇落雁體」（只放網站用到的字，`fonts/title-chenyu.woff2`），內文用芫荽。⚙️ →「🔤 標題字體」可以在這支手機改成霞鶩文楷或芫荽，只影響自己的裝置。
4. 改了網站用到的字（新的景點名稱等）若標題出現缺字，要重新產生 `title-chenyu.woff2` 子集。

## 第一次使用（家人同步）

和北海道版共用同一個 Supabase 專案，但資料存在另一張 `norway_sync` 資料表，兩個網站不會互相覆蓋；照片放在同一個 `trip-media` 空間的 `norway/` 資料夾。

1. 到 Supabase → **SQL Editor → New query**，貼上 `SUPABASE_SETUP.sql` 全部內容，按 **Run**（只要一次）。
2. 家人沿用北海道版的帳號登入即可。
3. 沒執行 SQL 前，登入後標頭會顯示「尚未建立 norway_sync 資料表」，資料先存在手機上，執行後會自動同步。

`config.js` 已填好與北海道版相同的網址與金鑰。之後更新網站時不要覆蓋這個檔案。兩個都留空＝單機預覽模式（不用登入，資料只存在這台裝置）。

## 怎麼改內容

- 每天的行程、景點、住宿分段、交通步驟：`app.js` 的「狐光漫遊：挪威 20 天每日行程」區塊（`days`、`STAY_SEGMENTS`、`transportPlans`）。
- 交通與票券預設清單：`defaultDocsData`；出發前待辦：`TODO_SEED`；行李：`defaultPackData`；規範：`defaultRulesData`；即時連結：`LIVE_SEED`。
- 角落呆維的小知識與碎碎念：`daiwei/daiwei-content.js`。
- 配色與字體：`style.css` 最後的「狐光漫遊・淺色主題」；預設字體改 `:root` 的 `--title`、`--hand`、`--script`。
- 改了內建景點的順序或數量時，網站會先自動存一份快照（⚙️ → 快照）。
- 家人在網站上改的內容存在 Supabase，不會因為更新程式而消失。
